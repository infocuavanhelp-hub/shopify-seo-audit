# shopify-seo-audit

An open-source toolkit for auditing and improving the SEO of Shopify stores: catalogue-wide product and collection checks, image SEO, storefront technical checks, a transparent scoring model, and suggestions that never invent product facts or change a store without approval.

> **Status: planning.** There is no working software in this repository yet. See [docs/PLAN.md](docs/PLAN.md) for the research, architecture and milestones. This README will only describe features once they are implemented and tested.

## Planned scope

- Product and collection SEO auditor (Shopify GraphQL Admin API, read-only scopes)
- Storefront technical SEO crawler (robots.txt, sitemap, status codes, canonicals, headings, JSON-LD)
- Image SEO analyser
- Documented, rule-based scoring
- Suggestion generator that uses only data already in the product
- Embedded Shopify admin app with dashboard and exports
- CLI for local and CI use
